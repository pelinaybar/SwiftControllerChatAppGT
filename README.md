# UIKit Chat App Foundation

An early UIKit project created as the starting point for a chat application and controller-based iOS architecture.

![Swift](https://img.shields.io/badge/Swift-F05138?logo=swift&logoColor=white)
![UIKit](https://img.shields.io/badge/UIKit-2396F3?logo=apple&logoColor=white)
![Core Data](https://img.shields.io/badge/Core_Data-1575F9?logo=apple&logoColor=white)

## Included

- UIKit application lifecycle
- Storyboard-based interface
- Core Data model foundation
- Swift Package configuration
- Initial view-controller structure

## Run

Open `SwiftChatAppGT.xcodeproj` in Xcode, resolve packages, select a simulator, and run.

## Status

This is a starter/prototype repository. The chat experience is not presented as a production-ready feature.
